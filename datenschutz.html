Andere Daten werden automatisch oder nach Ihrer Einwilligung beim Besuch der Website durch unsere IT-Systeme erfasst. Das sind vor allem technische Daten (z. B. Internetbrowser, Betriebssystem oder Uhrzeit des Seitenaufrufs). Die Erfassung dieser Daten erfolgt automatisch, sobald Sie diese Website betreten.

Ein Teil der Daten wird erhoben, um eine fehlerfreie Bereitstellung der Website zu gewährleisten. Andere Daten können zur Analyse Ihres Nutzerverhaltens verwendet werden.

Sie haben außerdem ein Recht, die Berichtigung oder Löschung dieser Daten zu verlangen. Wenn Sie eine Einwilligung zur Datenverarbeitung erteilt haben, können Sie diese Einwilligung jederzeit für die Zukunft widerrufen. Außerdem haben Sie das Recht, unter bestimmten Umständen die Einschränkung der Verarbeitung Ihrer personenbezogenen Daten zu verlangen. Des Weiteren steht Ihnen ein Beschwerderecht bei der zuständigen Aufsichtsbehörde zu.

Diese Seite nutzt zur einheitlichen Darstellung von Schriftarten so genannte Google Fonts, die von Google bereitgestellt werden. Beim Aufruf einer Seite lädt Ihr Browser die benötigten Fonts in ihren Browsercache, um Texte und Schriftarten korrekt anzuzeigen.

Der Websitebetreiber hat ein berechtigtes Interesse an der einheitlichen Darstellung des Schriftbildes auf seiner Website.

Wenn Ihr Browser Google Fonts nicht unterstützt, wird eine Standardschrift von Ihrem Computer genutzt.

Das Unternehmen verfügt über eine Zertifizierung nach dem „EU-US Data Privacy Framework" (DPF), der die Einhaltung europäischer Datenschutzstandards bei Datenverarbeitungen in den USA gewährleisten soll.

Supabase

Diese Website nutzt Supabase (Supabase Inc., 970 Trestle Glen Rd, Oakland, CA 94610, USA) als Datenbankdienstleister. Supabase wird eingesetzt für die Speicherung von Challenge-Einträgen im CrossFit-Bereich, Gaming-Highscores sowie für das optionale Profil-System.

Gaming-Highscores können weiterhin vollständig anonym mit einem frei gewählten Namen eingetragen werden, ohne dass ein Profil erforderlich ist.

Wer sich freiwillig für ein Profil registriert (nutzbar für CrossFit-Challenges und optional auch für Gaming), dem werden zusätzlich folgende Daten gespeichert:

  • Frei gewählter Login-Name (kein Klarname erforderlich) sowie ein optionaler, ebenfalls frei wählbarer Anzeigename
  • Passwort — ausschließlich als kryptografischer Hash (bcrypt) gespeichert, nicht im Klartext
  • Ein Wiederherstellungscode zum eigenständigen Zurücksetzen des Passworts — ebenfalls nur als Hash gespeichert
  • Challenge-Fortschritt, Spiel-Scores und Abstimmungen, die über das Profil einer Person eindeutig zugeordnet werden
  • Zeitpunkt der Registrierung bzw. des jeweiligen Eintrags

Das Profil dient dazu, Einträge eindeutig einer Person zuzuordnen (etwa bei mehreren Personen mit demselben Namen) und Fortschritt über den CrossFit- und Gaming-Bereich hinweg konsistent anzuzeigen. Diese Daten werden ausschließlich zur Anzeige der Rangliste bzw. des Profils verwendet und nicht an Dritte weitergegeben. Die Verarbeitung erfolgt auf Grundlage von Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse an der Bereitstellung der Funktionen). Eine Löschung Ihres Profils inkl. aller gespeicherten Daten kann jederzeit per E-Mail an info@onlymakkus.de beantragt werden.

Weitere Informationen zum Datenschutz bei Supabase finden Sie unter: supabase.com/privacy.
